# Work Log - 2026-06-21

Project: `C:\Development\projects\rust-text-editor`

## Summary

- Built the next Hotaru version around a vault-first note-taking workflow, with a persistent Vault sidebar, safer vault file management, CodeMirror editing, split preview, keyboard command support, wiki links/backlinks, and Obsidian-style tags.
- Iterated on usability based on manual testing screenshots: simplified the editor back to source text for responsiveness, compacted the Vault file list, made sidebar sizing adjustable, and added build metadata to the title/header for release verification.

## Completed Work

- Added a persistent Vault sidebar with New, Refresh, filtering, sorting, compact filename-only rows, per-file `...` actions, backlinks, current-note tags, adjustable width, and configurable file-list font size.
- Changed Vault folder selection so choosing a folder uses that folder directly instead of always creating a nested `hotaru-valut`; default first-run vault still preserves the legacy folder name.
- Extended Rust Vault metadata with relative path, extension, size, timestamps, draft status, and tags.
- Added safe Rust commands for named note creation, rename, delete, duplicate, backlinks scanning, and path traversal protection.
- Added `[[wiki links]]` that open existing notes or create missing notes, plus backlink scanning.
- Added Obsidian-style tag extraction for inline `#tag`, nested `#tag/subtag`, and YAML `tags:` frontmatter; numeric-only tags are ignored and fenced code blocks are skipped.
- Added CodeMirror as the editor engine, then changed the normal editing pane to source-text mode only after live preview proved too slow on large tables.
- Preserved a right-side Markdown preview pane with Mermaid, JSON, Excalidraw, raw HTML support, and wiki-link handling.
- Added a command registry and command palette with keyboard shortcuts for common file, view, search, and formatting actions.
- Added table Markdown helpers and tests for Markdown table parsing/serialization.
- Added build metadata generation so the app displays build number and updated timestamp.
