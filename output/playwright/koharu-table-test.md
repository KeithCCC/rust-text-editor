# 表の直接編集テスト

セルをクリックして入力してください。Tab で次のセル、Shift+Enter でセル内改行、Alt+↓ で操作メニューを開きます。

| 方針 |
| --- |
| **既存 CodeMirror に表専用の編集機能を追加**<br><br>日本語を入力して保存してください。 |

## 操作確認

| 項目 | 確認内容 |
| --- | --- |
| 日本語変換 | 変換を Enter で確定し、Ctrl+S で保存 |
| セル移動 | Tab / Shift+Tab |
| セル内改行 | Shift+Enter |
| 履歴 | Ctrl+Z / Ctrl+Y |
| 行と列 | ⋯ または Alt+↓ のメニュー |

保存後にこのファイルを開き直し、入力した内容が残っていることを確認してください。
