# 共通ツールバーの確認

セルをクリックすると、表の上に「行・列・配置・…」が表示されます。
選択位置を確認して操作してください。「…」からソース編集もできます。

| 項目 | 確認内容 |
| --- | --- |
| 行 | 下に追加・選択行を削除 |
| 列 | 右に追加・選択列を削除 |
| 配置 | 選択列の左・中央・右揃え |
| その他 | ソースを編集・表の後へ移動 |

## 別の表

| 名前 | 値 |
| --- | --- |
| 日本語 | こちらの表を選ぶと、この表の操作だけが表示されます。 |

Alt+↓でメニューを開き、Escapeでセルに戻れます。
