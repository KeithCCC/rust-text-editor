# Koharu UI テスト

今回の変更を試すための文書です。

## 確認すること

- 起動直後は編集画面のみで、アウトラインとプレビューが閉じていること。
- 上部の書式アイコンにマウスを重ねると、操作名が表示されること。
- 「表示 → 外観」から文字サイズを変更できること。
- 「編集 → 検索」でこの文書を検索できること。
- 「分割」に切り替えると、右側で仕上がりを確認できること。
- 「ファイル → PDFとしてエクスポート…」からPDFを保存できること。
